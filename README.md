# Machine Learning Assignments

This repository contains my Machine Learning assignments completed as part of my M.Sc. Bioinformatics coursework.

## Contents

- **01_Classification.ipynb** – Classification techniques
- **02_Clustering.ipynb** – Clustering methods
- **03_RNASeq_ML.ipynb** – Machine Learning applications in RNA-seq analysis
- **04_ML_Libraries.ipynb** – Introduction to Python Machine Learning libraries

## Datasets

- `iris.csv.csv` – Iris dataset
- `GSE263566_ageingRNAcounts.csv.gz` – RNA-seq gene expression count dataset
- `archive/` – Additional datasets in different file formats

## Tools and Libraries

Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
